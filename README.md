# Pratiksha Sharma — Product Manager Portfolio

A responsive, single-page portfolio website showcasing product management, operations, CRM/support systems, PRDs, go-to-market work, projects, tools, and professional background.

## Files
- `index.html` — the complete website. CSS, JavaScript, and most imagery are embedded in this file.
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing.

## Preview on your computer
1. Download and extract the ZIP.
2. Open `index.html` in a browser such as Chrome or Edge.

## Upload to a GitHub repository
**Important:** Extract the ZIP first. Upload the files inside it—not the ZIP archive itself—so `index.html` appears directly in the repository's root.

1. Open your GitHub repository.
2. Select **Add file → Upload files**.
3. Drag in `index.html`, `README.md`, and `.nojekyll` from the extracted folder.
4. Commit the changes to your main branch.

## Publish with GitHub Pages
1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select your main branch and the `/(root)` folder, then save.
4. Wait for deployment. GitHub will show your website URL in the Pages settings.

The site loads Google Fonts from the internet; system fallback fonts are used if those fonts cannot load. After publishing, check the navigation, interactive tabs, and PRD tables on both desktop and mobile.
